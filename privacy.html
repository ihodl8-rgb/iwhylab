Privacy Policy

WhyLab Uploader · Last updated: November 24, 2026

What this app is

WhyLab Uploader is a personal tool used only by the owner of the YouTube channel WhyLab (@iWhyLab). It runs on the owner's own computer.

What data it accesses

With the owner's authorization through Google OAuth, the app uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos, titles, descriptions, tags and thumbnails to the owner's own channel, and update their privacy status;
  • read the owner's own channel and video statistics (such as views, watch time and subscriber changes).

How data is stored

The OAuth access and refresh tokens and any downloaded analytics are stored only on the owner's computer. Nothing is sent to any server other than Google's own APIs.

Sharing

The app does not collect data from anyone other than the channel owner, and it does not sell, share, or transfer any data to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API use is also subject to the YouTube Terms of Service and the Google Privacy Policy.
